# Percobaan-ESP8266-Node-MCU-Menguhubungkan-ke-MQTT-dengan-JSON

Disini saya mencoba untuk menguhubungkan ESP (Microcontroler) dengan Protokol Komunikasi MQTT

dengan bantuan JSON agar memudahkan untuk 2 arah, jadi esp (microcontroler) dapat dijalankan perintahnya di mqtt dengan bantuan JSON

*JSON* itu salah satu format data berbasis teks yang ringan, mudah dibaca dan ditulis oleh manusia, serta mudah diproses oleh komputer
